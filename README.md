# Jhoshef Morillo — Portafolio

Portafolio personal de **Jhoshef Morillo**, estudiante de Ingeniería de Software (SENATI) enfocado en desarrollo web frontend.

🔗 **Demo:** https://jhoshefmorillo.github.io/portfolio/

## Sobre el proyecto

Sitio de una sola página construido en **HTML, CSS y JavaScript puro** (sin frameworks), con:

- 🌐 **Bilingüe (ES/EN)** — cambio de idioma en tiempo real, con la preferencia guardada en `localStorage`.
- 🎨 **3 temas de color** (Midnight Blue, Emerald Slate, Minimal Purple), seleccionables desde un menú, también persistentes.
- ✨ Efecto de luz que sigue el cursor, animaciones al abrir menús y transición al cambiar de tema.
- 📱 Diseño responsive (mobile-first en breakpoint de 768px).
- 🔍 Navegación activa según la sección visible (`IntersectionObserver`) y scroll suave personalizado.
- 🖼️ Meta Open Graph para que el link se vea con imagen al compartirlo (WhatsApp, LinkedIn, etc.).

## Tecnologías

- HTML5
- CSS3 (variables CSS para temas, Grid, Flexbox)
- JavaScript (Vanilla, sin librerías)

## Cómo verlo localmente

No requiere instalación ni backend. Basta con abrir `index.html` en el navegador, aunque se recomienda usar **Live Server** (extensión de VS Code) para evitar problemas de rutas relativas.
